# 🏛️ ROXSTONE: THE ARCHITECTURAL MARBLE GALLERY 🌲✨

### 🔗 [LIVE DEMO: foxstone-marble.vercel.app](https://foxstone-marble.vercel.app) 🚀

---

**Roxstone** is a premium 3D digital gallery designed for elite architects and high-end marble acquisition. Experience nature's finest art with sub-second performance. 💎🏛️

---

## 💎 CORE "WOW" FEATURES ✨

- **🌲 Forest & Gold Luxe**: A custom design system pairing Deep Forest Green with Burnished Gold accents. 🎗️
- **🕋 3D Deep Neumorphism**: Custom-coded 3-layer shadows that make marble cards feel like physical slabs. 💎
- **📽️ 60fps Cinematic Parallax**: Layered depth transitions for a museum-like browsing experience. 🌪️
- **📲 Ultra-Responsive Design**: Specialized **70% UI scaling** for a dense, professional catalog feel on mobile devices. 📱
- **🛠️ High-Performance Engine**: Built with **React 19**, **Framer Motion**, and **Tailwind CSS v4** for maximum fluidity. ⚡

---

## 🛠️ TECH STACK ⚙️

- **⚛️ Core**: React 19 + TypeScript
- **🚀 Build**: Vite
- **🎨 Styling**: Tailwind CSS v4
- **🌪️ Motion**: Framer Motion
- **☁️ Deploy**: Vercel

---

## 🏗️ LOCAL SETUP 🛠️

1. **Clone**: `git clone https://github.com/USERNAME/foxstone-marble.git`
2. **Install**: `npm install`
3. **Launch**: `npm run dev`
